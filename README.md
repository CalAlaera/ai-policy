This is a resource for those who wish to easily exclude AI agents from their repositories.

This repository is licensed CC0, meaning you can do whatever you want with it, and you don't even need to give attribution.

Add the AGENTS.md file to your repo, it tells AI agents to go away. The presence of an AGENTS.md file is a signal that AI was used in naïve approaches such as slopscan, so the current recommendation seems to be to add an empty AAA-NO-SLOP file which humans'll see first. CONTRIBUTING.md was the original file, you can take ideas from it if you want to, or just use it as-is, or ignore it.

Pull requests are welcome should anyone wish to improve this repo. Contributions are accepted under CC0.
